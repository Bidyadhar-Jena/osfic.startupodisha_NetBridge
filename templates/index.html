Prototype notice

This application uses fictional, device-local wallet balances. It does not transfer real money or connect to a bank, UPI, or payment network. The customer scans the merchant request QR, then the merchant types a short confirmation code after approval. Offline records stay on their own device and cannot prevent spending from another copy of the demo wallet.

Install NetBridge

Open and install NetBridge while it is available, then the cached customer app can load without the server. The merchant PC also needs to open the dashboard once before both devices go offline.

If no install prompt appears, open your browser menu and choose Install app or Add to Home screen.
